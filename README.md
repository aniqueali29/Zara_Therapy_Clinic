# 🌸 Zara Therapy Clinic - Holistic Health & Wellness Portal

![Zara Therapy Clinic Banner](assets/img/therapy.jpeg)

**Zara Therapy Clinic** is an elegant, responsive web platform designed to assist clients in exploring therapeutic care, booking appointments online, discovering medical and beauty therapy treatments, and purchasing wellness products.

🔗 **Live Website:** [https://aniqueali29.github.io](https://aniqueali29.github.io)

---

## ✨ Key Features

- 🏥 **Comprehensive Therapy Services:** Explore Medical Therapy, Technical Therapy, and Beauty Therapy solutions tailored to client needs.
- 📅 **Online Appointment Reservation:** Simple, interactive scheduling form for booking therapy sessions.
- 🛍️ **Wellness Product Store & Cart:** Browse health products, add items to cart, and manage orders online.
- 🖼️ **Therapy Moments Gallery:** Visual showcase of therapy facilities, treatment rooms, and client wellness moments.
- 🔐 **User Authentication System:** Client registration, sign-in modal, and session logout functionality.
- 📱 **Interactive UI & Animations:** Built with AOS (Animate on Scroll) effects, responsive sidebar, Bootstrap 5 navbar, and smooth back-to-top navigation.

---

## 🛠️ Built With

- **HTML5** - Clean semantic web structure
- **CSS3** - Custom styling, gradients, and responsive layouts
- **JavaScript (ES6+)** - Dynamic shopping cart, authentication handlers, and navigation controls
- **Bootstrap 5.3** - Grid layout, modals, dropdowns, and responsive navigation
- **AOS (Animate On Scroll)** - Smooth page scroll reveal animations
- **Font Awesome 6** - Vector icons for services and UI elements
- **jQuery** - Simplified DOM manipulation and event handlers

## 🚀 How to Run Locally

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/aniqueali29/Zara_Therapy_Clinic.git
   ```
2. **Navigate into the directory:**
   ```bash
   cd Zara_Therapy_Clinic
   ```
3. **Open `index.html`** in any modern web browser or run using VS Code Live Server.
